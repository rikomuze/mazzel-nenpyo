# MAZZEL 年表

MAZZELの出演・ライブ・リリースなどを年・月ごとにまとめた、ファンによる非公式の年表サイトです。

## ファイルの構成

| 場所 | 中身 |
| --- | --- |
| `index.html` | 年表ページ本体（見た目と絞り込み・検索の仕組み） |
| `data/events.json` | 出来事のデータ |
| `AGENTS.md` | 更新するときのルール（AI向け・人向け共通） |
| `images/` | 出来事に付ける画像 |

## 出来事を追加・修正する

書き方・載せる基準・写真の入れ方は [`AGENTS.md`](AGENTS.md) にまとめています。AI に更新を頼むときは「AGENTS.md を読んでから作業して」と伝えてください。
