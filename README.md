# MAZZEL 年表

MAZZELの出演・ライブ・リリースなどを年・月ごとにまとめた、ファンによる非公式の年表サイトです。

## ファイルの構成

| 場所 | 中身 |
| --- | --- |
| `index.html` | 年表ページ本体（見た目と絞り込み・検索の仕組み） |
| `data/events.json` | 出来事のデータ（1行に1件） |
| `images/` | 出来事に付ける画像 |

## 出来事を追加・修正する

`data/events.json` を開き、鉛筆マーク（Edit）から編集します。1行が1件で、次の形をしています。

```json
{"id": "e556", "d": "2026-11-02", "e": null, "k": ["ライブ"], "t": "公演名\n会場名", "img": []}
```

- `id`：ほかと重ならない文字列（新しく足すときは `e556`, `e557` … のように続ける）
- `d`：日付（`YYYY-MM-DD`）
- `e`：終了日。期間がなければ `null`
- `k`：種別。`ライブ` `出演` `リリース` `MV` `配信` `雑誌` `SNS` `その他` から選ぶ（複数可、なしなら `[]`）
- `t`：出来事。`\n` のあとは会場などの補足として小さく表示されます
- `img`：画像のパス。例 `["images/2026-11-02-live.jpg"]`

行と行の間はカンマ `,` で区切ります。最後の行のあとにはカンマを付けません。

## 画像を追加する

1. `images` フォルダを開き、「Add file」→「Upload files」で画像をアップロードします。
2. `data/events.json` の該当する行の `img` に、`"images/ファイル名"` を書き足します。

写真のある出来事は、その月のページに写真付きで大きく並びます。写真がない出来事は、月ごとの番号つき一覧に入ります。

写真は縦長・横長それぞれの形のまま、行ごとに高さをそろえて並びます（切り抜きはしません）。

その月で特に大きく見せたい出来事には `"feature": true` を足すと、その写真だけ1行を使って大きく表示されます。

```json
{"id": "e116", "d": "2024-06-01", "e": null, "k": ["ライブ"], "t": "公演名\n会場名", "img": ["images/2024-06-01.jpg"], "feature": true}
```
